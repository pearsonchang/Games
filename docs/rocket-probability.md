# 小火箭积分模型

每局消耗 50 模拟积分。理论返还率为 97%，在 1–10 倍内预先选择任意收取倍率，理论平均返还 48.5 积分（含投入），净收益为 −1.5 积分。短期结果不保证亏损；这也不是为每个玩家强制安排的输赢序列。

## 概率与结算

每局只抽一次独立均匀随机数 U，取坠毁倍率 C = 0.97 / U。U ≥ 0.97 的约 3% 局在开局即坠毁，先扣除投入，不能抢先收取。

对于 1 ≤ m ≤ 10，存活到倍率 m 的概率为 P(C > m) = 0.97 / m，因此 E[到账] = (0.97 / m) × 50m = 48.5，E[净收益] = −1.5。

| 收取倍率 | 理论成功概率 | 成功到账 | 每局理论净收益 |
| --- | --- | --- | --- |
| 1× | 97% | 50 | −1.5 |
| 1.2× | 80.8333% | 60 | −1.5 |
| 1.5× | 64.6667% | 75 | −1.5 |
| 2× | 48.5% | 100 | −1.5 |
| 5× | 19.4% | 250 | −1.5 |
| 10× | 9.7% | 500 | −1.5 |

视觉增长保持 m(t) = 1 + 0.12t + 0.004t²。展示倍率向下保留两位小数，积分按展示倍率精确结算，可出现 0.5 积分。任意时刻收取的实际返还率不高于约 97%；向下取整、帧间延迟会使其略低。达到 10×（约 34.75 秒）自动收取 500 积分，避免有限时长截断额外损失尾部奖励。

后台或隐藏标签页恢复时，先比较坠毁时刻和上限时刻，按最先发生的事件结算；不会把先坠毁的局误判为达到上限。相同时间戳时坠毁优先，每局至多入账一次。

## 为什么观察动效不能提高期望

存活至 a 倍后，继续至 b 倍的条件存活概率是 a / b。未取整的潜在到账过程是有界停止的鞅；同一局中依据已显示信息改变收取时机，也不能把开局前的期望提高到投入以上。显示倍率向下取整不会提高收益。达到上限、主动收取或不再操作均已定义结算方式。

这个结论依赖玩家只能观察正常游戏信息、各局抽样独立且无法预知结果。喷焰、音效和背景只依赖已流逝时间，不使用剩余飞行时间或坠毁时间。没有保护期，不依据玩家余额、历史盈亏或连胜修改抽样结果。历史结果不能预测下一局。

## 验证与边界

`tests/rocket-engine.test.cjs` 对 9 个目标倍率各运行 100,000 局分层均匀抽样，共 900,000 局，验证存活分布、负期望及到账；另验证即时坠毁、精确时刻冲突、上限、重复收取和无未来信号。统计抽样用于验证实现，概率公式给出理论依据。

当前是浏览器内的模拟积分 Demo。用户可修改客户端或读取其内部状态；此数学模型不构成真实资产的防作弊保障。若后续接入真实账户或资产，需将随机结果、时钟、扣款和结算移到可信后端，并单独设计可审计机制。
